A huge panda smashes through the screen of an old CRT television and lunges out hugging a tall bamboo shoot, while a young girl in a pink dress flinches back and a little dog yaps at the commotion, all inside a snug, warmly lit living room. The picture ships as a 512×1024 JPEG. The program decodes it and writes it to /output/entry.png. The bundled base64 payload is now stored as a single unwrapped line, with no line breaks inside it.
